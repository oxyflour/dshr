# 阶段 5 报告 · DSH rc.5 会话和 Agent 编排

> 2026-11-22 完成。Windows 使用 `0.2.2-rc.5` 官方工具包、捆绑 Node 24 和本机进程沙箱。

| 工具包 | 实测 |
|---|---|
| `goal` | 根用户轮次创建目标。自动轮次受预算限制，拒绝创建新目标。重启后保留状态和版本，解除自动继续授权。过期版本拒绝，匹配版本可完成 |
| `session-query` | 通过五项搜索、读取与追踪调用。对同一工作区但不同树、不同工作区以及未知会话返回同一拒绝结果 |
| `subagent`、`subagent-control` | 创建独立子会话，等待并在父会话观察一次完成提示，重新向空闲子 Agent 投递消息，记录子任务失败。流程取消时记录实际子会话中断 |
| `agent-team` | 创建带依赖的任务，验证阻塞认领、循环依赖和过期版本拒绝。认领和完成后重启，依赖任务变为可认领。其他根会话无法读取任务板 |
| `workflow` | 官方引擎在受限进程执行脚本，启动子会话并返回实际结果。取消流程时终结工具调用和活动子会话 |
| `ralph` | 两轮启动不同子会话，经本地模型端点验证第二轮收到首轮结构化交接，最终返回完成报告和证据 |
| `schedule` | 创建 RRULE 任务，重启后领取上一次已到期发生时间。再重启时未重复投递。可查看投递收据、拒绝过期更新并暂停任务 |

八项 `stage5_official_` 专项用例通过。调度用例将已创建任务的持久记录移至同一规则的上一个真实发生时间，以复现进程重启时的到期情形。[验收入口](../../tools/official-rc5-gate.ps1) · [会话与编排契约](../spec/sidecar-rpc.md#716-官方目标与会话查询)

补充验证使用本地模型端点启动官方子 Agent。`working_directory({})` 返回分配给子会话的目录，模型收到路径查询说明。需要交互审批的 PowerShell 调用返回后台审批不可用，并提示交回父会话。

调度当前限 `this_session`，在目标会话下一次模型步投递。等待中的子 Agent 会在下一轮处理追加消息，交给父会话的结果在后续模型步领取。工作流支持前台使用。后续仍需验证空闲唤起、新会话调度、工作流后台执行、切换子模型和图形桌面交互。会话搜索使用 Rust 日志投影和本地字面匹配，范围、分页与限制见矩阵。 [兼容矩阵](../spec/dsh-compat-mapping.md#兼容矩阵) · [作者指南](../plugin-authoring.md#启用-dsh-rc5-会话和编排工具)
