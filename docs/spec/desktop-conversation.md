# 桌面对话控制

工作区按最近更新展示主会话，默认最多五条。点击「展开其余 X 个会话」继续显示下一批，全部显示后可收起。当前会话所在工作区可自动露出近期选中的会话。搜索覆盖当前归档筛选下的全部主会话。

会话行的归档操作将会话移到「已归档」筛选。归档保存于本地会话元数据 `<session_id>.meta.json` 的 `archived` 字段，旧会话默认未归档。归档保留会话日志、附件和子会话。归档当前会话时，桌面切到下一条未归档会话，或在当前工作区打开新会话。归档不会停止任务，桌面正生成的会话及被其他写入者锁定的会话须等写入结束再归档。已归档会话可从「已归档」列表取消归档后打开。

会话标题旁显示已绑定的模式。会话有子智能体时，点击标题旁入口可以切换到同一会话树中的子会话，并返回主会话。切换沿用生成中禁止切换的桌面行为。对话右上角提供会话操作菜单和插件视图侧栏入口。轮次导航可从 `/turns` 打开，宽窗仍可点击轮次标记跳转。

输入区的模型菜单提供「推理等级」。选择跟随各模型连接保存，下次请求生效。默认项沿用环境变量和服务端设置。DeepSeek 模型支持关闭、低、高和最高，关闭发送 `thinking.type=disabled`，显式等级启用思考并发送 `reasoning_effort`。OpenAI 兼容连接发送显式的低、高和最高，其接受的值由连接的服务决定。

模型的推理文本和连续工具调用归入可展开的过程，默认收起，保留调用顺序和结果。模型正文仍可单独复制。停止请求立即显示进行中的状态，轮次结束后显示「已停止」，已生成的文本可继续查看。点击复制后，当前消息短暂显示勾选反馈。

模型生成和等待审批时都可以切换工具权限。「工具免审批」放行正在等待的普通工具审批和后续普通工具调用，包括官方文件工具的工作区内写入。「只读」拒绝仍在等待许可的写入和执行类操作。模式变化按当前策略重新裁决，工作区边界、文件版本校验、写前快照以及创造模式的构建和试用确认继续生效。锁定为逐次审批的启动模式保留该限制。

普通工具的审批卡片提供「始终允许」。它批准本次请求，并在系统凭据库中保存授权。授权随当前数据目录隔离，仅供同一会话、工作区和工具定义使用，重启后继续有效。官方文件工具的调用与同次调用发出的写入请求共享这项授权。授权只替代需要用户回答的普通审批。只读限制、逐次审批锁定、插件构建和试用确认仍按各自规则执行。保存授权失败时，继续显示审批卡，用户可重试或选择「允许一次」。

用隔离数据目录、本地模型服务和工作区验收。从「工作区写入」发起官方 `write`，分别在工具审批和文件写入审批处切到「工具免审批」。当前调用应继续执行，同轮下一次写入应直接运行，工作区外写入仍应失败。从待审批切到「只读」应结束等待并拒绝写入。

在 `write` 的审批卡上选择「始终允许」，当前写入及同会话后续 `write` 应直接完成，包括重启后的后续调用。不同工具和不同会话继续按当前模式审批。
