# 桌面 Agent 预设

> Draft。对照原版的 [Agent 预设注册表](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/preset/agent-preset-registry) 和 [Profile 热重载](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/boot/app-boot)。

## 声明与选择

桌面官方 Sidecar 读取 `DSHR_LOADER_BUNDLE` 和有序的 `DSHR_LOADER_PATCH`，识别两类 DSH 声明。启用的 `@deepseek-ai/dsh-agent-preset` 行使用 `config.id` 作为预设标识、`config.plugins` 作为有序的子插件条目列表。Loader 行的 `id` 用于 patch 寻址。可通过 `@deepseek-ai/dsh-agent-preset-registry` 的 `config.default` 指定默认预设。子条目支持本仓库的静态插件字段和 group，适用同样的模块解析。仅支持工具和已经接入的宿主服务。

新会话输入卡上方在工作区旁显示当前模式，点击可选择标准模式、创造模式或当前 Sidecar 提供的其他预设。新建默认采用 Loader 的默认预设，未配置时使用标准模式。同一个空白根会话可改选，保留 ID、工作区、输入草稿和附件。改选在会话写锁下复查日志，只有日志仅含 `session.created` 时可以原子更新其中的 `preset`。标准模式清除该字段，创造模式选择 `cordis`。空白界面改选工作区时，新工作区中的空白会话继承当前选择。未知或不可用的预设在写入前报告错误，已经开始的会话和子会话无法改选。

`/creator` 仍可直接新建创造会话。宿主自带一个可覆盖的最小 `cordis` 预设，此前的 `dshr-creator` 会话仍可打开。子会话默认加入父会话的同一修订，显式指定预设时使用其当前修订。恢复时从日志读取 ID，在当前宿主上重新绑定。

## 修订、热重载和工具

每个工作区的 Sidecar 保持已发布的预设修订和会话引用。选择同一修订的会话共享该修订装载的插件实例。每个会话仍有自己的调用身份、工具覆盖和宿主服务上下文。解析顺序为会话工具、预设工具、全局工具。调用仍使用当步模型快照的注册 ID。

设置 `DSHR_LOADER_BUNDLE` 时，桌面在后台每 500 毫秒检查 bundle、patch 和 Loader 展开的 include。连续两次解析得到相同配置后，自动发布到已启动的工作区 Sidecar，空闲时无需切换会话或发送消息。发布和工具轮次串行。轮次或审批占用宿主时，后台发布延后至宿主可用。首次绑定、切换工作区和轮次开始仍会检查当前配置。

相同子插件列表复用修订。子插件列表变化后创建新修订，已经绑定的会话继续使用旧实例，继承其绑定的子会话仍加入该修订。最后一个会话引用释放后卸载已退役的插件。配置读取或解析失败时，保留最后一次成功发布的目录，显示诊断并在文件修复后自动重试。可解析但插件装载失败的修订保留诊断，并拒绝新绑定。显式重启 Sidecar 或进程退出后按当前定义重建。桌面空白会话保存新选择后，宿主释放旧预设绑定并绑定新选择。已选同一预设时保留当前修订。

这是配置重读。DSH 的包安装管理、Host 全图热替换、任意 `!!js`、源码热替换、预设服务隔离域、技能和提示词插件需要相应适配。较新上游的 `preset` 子项 patch 语法也需要适配。

## 验收

| 用例 | 验证内容 |
|---|---|
| `M3-PRESET-001` | 声明、默认值、patch 全量替换与非法输入 |
| `M3-PRESET-002` | 同修订共享、热重载、旧会话保留、子会话继承、退役回收 |
| `M3-PRESET-003` | 预设插件损坏、未知选择和工具隔离 |
| `M3-PRESET-004` | 真实桌面会话重读文件、子会话继承旧修订、保留有效目录并报告解析错误、重启按当前定义恢复 |
| `M3-PRESET-005` | 空闲时后台发布 bundle 及 include/patch 变更，保留旧绑定和继承关系，错误修复后自动恢复 |
| `M3-PRESET-006` | 新会话界面从模式菜单改选并保留草稿和 ID，持久化与首轮工具集一致，开始后的会话拒绝改选 |
